# Ayush Verma Salon Website

A modern and responsive salon website built using HTML, CSS, and JavaScript.

## About the Project

This website is created for Ayush Verma Salon to showcase salon services, pricing, location, and contact information in a simple and professional way.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Design

4. Run the website using Live Server.
